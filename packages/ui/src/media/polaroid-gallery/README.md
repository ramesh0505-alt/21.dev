# Hanging Polaroid Gallery

Hanging Polaroid photos with wooden pegs and gentle hover swing physics.

## Installation

```bash
pnpm add motion clsx tailwind-merge lucide-react
```

## Usage

```tsx
import { PolaroidGallery } from '@/components/ui/polaroid-gallery';

export function Example() {
  return <PolaroidGallery />;
}
```
