# Text Shimmer

A subtle glowing text shimmer effect that animates across headline or badge text.

## Installation

```bash
pnpm add motion clsx tailwind-merge
```

## Usage

```tsx
import { TextShimmer } from '@/components/ui/text-shimmer';

export function Example() {
  return <TextShimmer>Next Generation Developer Platform</TextShimmer>;
}
```
